# Flow HR

Quiero crear una aplicación web SaaS profesional de gestión de recursos humanos para pequeñas y medianas empresas llamada PeopleFlow.

NO quiero una simple landing page. Quiero una aplicación web funcional e interactiva, con aspecto de software empresarial real que pueda presentar como demo a una empresa interesada en comprarlo.

OBJETIVO

PeopleFlow permite a una empresa gestionar empleados, fichajes, horarios, vacaciones, ausencias, documentos, tareas, evaluaciones, calendario y comunicaciones internas desde un único lugar.

La aplicación debe tener un diseño moderno, elegante, profesional y premium, similar a los mejores SaaS B2B actuales.

TECNOLOGÍA

Utiliza:

React + TypeScript

Tailwind CSS

Componentes modernos y reutilizables

Supabase para autenticación y base de datos

Diseño completamente responsive

Sidebar de navegación

Dashboard con tarjetas, gráficos, tablas y estadísticas

Modales para crear y editar información

Toast notifications

Dark mode opcional

La aplicación debe estar preparada para utilizar datos reales posteriormente.
